# StudentScholar — Assignment 3

Group repository for the StudentScholar software engineering assignment.

## Deliverables

- Activity diagrams for the Student, Teaching Staff, and Administrator functions
- Sequence diagrams for the three selected use cases
- Java skeleton projects derived from each sequence diagram
- Consolidated class diagram and postgraduate design-improvement discussion

## Teaching Staff contribution

The Teaching Staff contribution models the **Grade Submission** workflow:

1. Verify access to the assigned course.
2. Select an assessment and student submission.
3. Load the submission and rubric.
4. Optionally review a similarity report.
5. Record criterion marks and feedback.
6. Require justification for custom marks.
7. Calculate the total and save a draft grade.
